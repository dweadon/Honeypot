# Honeypot
Honeypot, is used to see methods attackers use for breaking into system and protect your machine/system from that

# Usage
First clone this repo:
```bash 
git clone git@github.com:dweadon/Honeypot.git <replace-me-with-folder-name>
```
Because this is localhost only, you have 2 files for testing:
```
client.py, main.py
```
client.py: Use this for connection to main.py (server side) and run it AFTER main.py
main.py: The main server that accepts users, shows attempts and predictions

This should be used on localhost only
